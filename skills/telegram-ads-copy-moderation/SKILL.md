# Telegram Ads Copy Moderation

Классовый skill: написание рекламных текстов/описаний для Telegram Ads, которые
проходят модерацию и одновременно описывают канал по сути. Дополняет защищённый
(bundled) `write-growth-copy`: тот про конверсионный копирайт вообще, этот — про
модерационные ограничения и стилевые правила оператора для копий каналов.

## When to use

- «Придумай описание канала на английском, нейтрально для модерации в Telegram Ads».
- «Напиши текст объявления для канала X».
- «Напиши примерно так же для остальных каналов портфеля».
- Любая копия, которая пойдёт в `validate_ad` / `create_ad`.

## Workflow

1. **Собери контекст канала перед написанием**: свежие посты через
   `telegram_research_inspect_channel(channel=..., post_limit=10)` + память
   портфеля (`~/.hermes/memory/projects/telegram-channel-portfolio/channel_profiles.md`,
   `project_profile.md`). Пиши по ФАКТИЧЕСКОМУ контенту, не по названию.
2. **Определи тип канала** → стиль:
   - AI/новостные каналы → нейтрально-фактический, описательный, без CTA.
   - Фанатские/комьюнити (футбол и т.п.) → эмоциональный, эмодзи
     (🔴⚽🌍🔥💯), engagement-рамка («fans, this is your home», «from every
     corner of the globe»), но без «#1» и непроверяемых рейтингов.
3. **Напиши варианты** (3–6; для нескольких каналов — см. правило структуры ниже).
4. **Обязательно прогони каждый через `telegram_ads_prepare_copy_variants`**
   (`promote_url=t.me/<channel>`, `variants=[...]`). Цикл:
   draft → validate → fix violations → re-validate → только потом выдавать.
   НЕ выдавать текст без проверки — валидатор ловит то, что ручной подсчёт пропускает.
5. **Отдай чистовые варианты** + пометь, какой рекомендован. Внешних действий
   (подача объявления, изменение описания канала) не выполнять.

## Hard constraints (подтверждены валидатором 2026-08)

- **≤160 символов** — иначе `Text length N exceeds limit 160`.
- **Одна строка, без переносов** — иначе `Text contains line breaks (forbidden)`.
  Многострочные примеры из реальных каналов (футбольные объявления с «Buy Ads»
  и переносами) в TG Ads НЕ проходят.
- Title объявления ≤32 символов (например `Daily AI News`).

## Moderation-neutral rules

- **Без непроверяемых превосходств**: `#1`, `best`, `largest`, `leading`,
  «most attractive» в ранжирующем смысле — триггеры модерации. Оператор: «надо
  что-то типа такого, но не номер один». Заменять на нейтральное
  («your daily AI news source», «full coverage of England's biggest league» —
  субъективное мнение фанатского канала проходит).
- **Без CTA/императивов по умолчанию**: для нейтральных описаний оператор хочет
  чисто описательный текст («без призыва» — никаких «Stay ahead», «Join»,
  «Don't miss»). CTA-стиль только если явно просят под рекламный угол.
- Hype-слова в контексте ОСВЕЩЕНИЯ новостей допустимы: `breakthroughs`,
  `emerging trends` — описывают охват, не гарантии.
- Строка `Buy Ads: @contact` формально допустима, но съедает символы и может
  вызвать вопросы модерации → добавлять только по явному запросу, контакт не
  выдумывать (спросить).
- Обещания дохода/заработка/финансовых результатов — запрещены всегда.

## Multi-channel portfolio rule (правило оператора)

- **Структура копий должна различаться между каналами** — «не должно быть
  одинаковой структуры на всех каналах». Не переиспользовать один шаблон:
  менять форму предложения (перечисление через двоеточие, разрыв через тире,
  audience-first, language-first, «curated look»-framing и т.п.).
- «Не один в один» — даже по смыслу близкие каналы получают разные формулировки.
- Язык: по умолчанию английский (по запросу «на анг»); для CN/KR каналов
  предложить перевод на язык канала — аудитория там не англоязычная.
- Вариант в одно предложение — ок.

## Pitfalls

- Многострочный текст в `prepare_copy_variants` → violation, а не «ок с
  предупреждением». Сначала проверка, потом обещание «прошло модерацию».
- Не выдавать «прошло полиси-проверку», если валидатор не вызывался.
- Не выдумывать контакт для строки «Buy Ads».
- Не смешивать стили: нейтральный текст для фанатского канала или эмоциональный
  для AI-новостного — оба промах.
